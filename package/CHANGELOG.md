# Changelog

## 1.0.2

- Added the public GitHub repository link to the package website and README.
- Published source code and packaged downloads on GitHub. Mod behavior is unchanged.

## 1.0.1

- Fixed: the free camera (F6) and hide interface (F7) hotkeys did nothing while another key was held, e.g. W while walking or Shift while flying fast.

## 1.0.0

- Free orbit camera: distance 0.4–40 m (wheel), tilt from below up to a top-down view (right mouse button).
- Field of view: config value, Shift + wheel to change, Shift + middle click to reset.
- Free camera (F6): fly around while your character stays in place.
- Hide the interface (F7) for clean screenshots.
- Optional: turn off camera collision to look through walls.
